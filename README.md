# puzzles-ios

The iOS version of Puzzles, an offline puzzle collection: Sudoku (classic and killer), Klondike Solitaire, Two Tone, Sightlines, Five Letters, Kakuro, Slide Out and Word Wheel.

Not started yet. It should have the same eight games as [puzzles-android](https://github.com/joclegg/puzzles-android) and [puzzles-web](https://github.com/joclegg/puzzles-web), and behave the same, downloading the shared banks that [puzzles-data](https://github.com/joclegg/puzzles-data) publishes.

The repository's settings and Actions secrets are managed by [joclegg-infra](https://github.com/joclegg/joclegg-infra).
